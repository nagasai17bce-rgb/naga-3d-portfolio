# Naga Sai — 3D AI Portfolio

A scroll-driven, 3D-inspired personal portfolio built with React, TypeScript, Vite, React Three Fiber and Three.js.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize

Edit `src/data/content.ts` for your profile, experience, projects and skills. The 3D scene is in `src/components/Scene.tsx`.

This implementation is an original portfolio inspired by the interaction pattern of the referenced open-source project, rather than copying its personal assets/content. The reference project describes a fixed 3D background with scrollable HTML content, React Three Fiber + TypeScript, and static deployment. See: https://github.com/dayinji/sen-3d-resume
